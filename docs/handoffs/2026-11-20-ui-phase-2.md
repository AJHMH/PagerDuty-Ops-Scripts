## Gotchas worth knowing

- **Stale `.pyc` after mutation checks.** A same-size edit made within the same second can reuse
  the old bytecode, so run `find . -name __pycache__ -prune -exec rm -rf {} +` before re-running.
- **New console scripts need a reinstall.** Without `pip install -e ".[dev,ui]"`, the
  entry-point sync test fails.
- **Windows line endings:**
  - `cli.run()` makes stdout untranslated, but stderr keeps CRLF on Windows.
  - The runner stores logs normalised to LF and keeps stdout byte-exact.
  - Fixtures must write files with `newline=""`.
  - Windows CI has caught all three of these.
- **Live calls from tests.** A gate test must never be able to reach a real engine command if
  the gate regresses. Use the fixture commands; one bypass test once made a real 401 call.
- **The gate parses argv** with the command's own argparse parser (`gate.check_arguments`),
  because text matching missed prefixes, attached values and short-option clusters.
- **FastAPI and future annotations.** `from __future__ import annotations` breaks FastAPI
  `Annotated` dependencies defined in a closure, so `app.py` doesn't use it.
- **Browser checks.** I used throwaway scratchpad scripts to start uvicorn with a fixed
  identity, the fixture catalog and `ui/dist`, then drove them with headless Playwright. The
  scripts (`launch.py`, `launch_op.py` and the `*.js` files) may have been cleared; recreate as
  needed. Build first with `npm --prefix ui run build`.
- **Codex** reviews only when a PR opens (or when someone comments `@codex review`), not on
  later pushes.
